# saulo-pro's Homebrew tap

## adit

[adit](https://github.com/saulo-pro/adit) keeps several WireGuard® tunnels up at once on macOS,
with a menu bar icon and a command line.

```sh
brew install saulo-pro/tap/adit
sudo adit install
```

Run `sudo adit install` again after every `brew upgrade adit`.

## How do I install these formulae?

`brew install saulo-pro/tap/<formula>`

Or `brew tap saulo-pro/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "saulo-pro/tap"
brew "<formula>"
```
